# Breaking Changes

This page contains important information about breaking changes in QuickBot versions and how to migrate your bots.

## Bot v6

### Overview
Bot v6 introduces significant changes to improve performance, security, and functionality. Please review these changes carefully before upgrading.

### Key Changes
- Updated bot execution engine
- Enhanced security measures
- Improved variable handling
- Modified block behavior for better consistency

### Migration Guide
1. Test your bot thoroughly in preview mode before publishing
2. Check all integrations and webhooks
3. Verify variable mappings and conditional logic
4. Update any custom scripts that may be affected

### Need Help?
If you encounter issues during migration, please [contact our support team](/support/contact).
