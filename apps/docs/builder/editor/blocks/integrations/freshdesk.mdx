# FreshDesk Integration

The FreshDesk integration allows you to automatically create support tickets and manage customer
inquiries through your QuickBot.

## Setup

### 1. Get FreshDesk API Key

1. Log into your FreshDesk account
2. Go to **Profile Settings** > **API Key**
3. Copy your API key

### 2. Configure the Block

1. Add the FreshDesk block to your flow
2. Enter your FreshDesk API key
3. Configure your FreshDesk domain (e.g., yourcompany.freshdesk.com)

## Actions

### Create Ticket

Automatically creates a new support ticket in FreshDesk with:

- Subject line
- Description
- Priority level
- Requester email
- Custom fields

### Get Ticket Types

Retrieves available ticket types from your FreshDesk instance to use in conditional logic.

## Use Cases

- Automatically create support tickets from bot conversations
- Escalate issues based on user responses
- Collect customer information for support cases
- Route inquiries to appropriate departments

## Troubleshooting

- Ensure your API key has proper permissions
- Verify your FreshDesk domain is correct
- Check that required fields are properly mapped
