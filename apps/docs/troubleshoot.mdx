# Troubleshooting

This guide helps you resolve common issues you might encounter while using QuickBot.

## Common Issues

### Bot Not Responding
- Check if your bot is published
- Verify webhook URLs are accessible
- Review bot flow logic for any loops or blocked paths

### Variables Not Working
- Ensure variable names are spelled correctly
- Check variable scoping and initialization
- Verify data types match expected values

### Integration Issues
- Verify API credentials are correct and not expired
- Check rate limits for third-party services
- Review integration-specific documentation

### Publishing Problems
- Ensure all required blocks are properly configured
- Check for validation errors in the flow
- Verify workspace permissions
